# Станция Миди

Миди (`yandexmidi`, платформа пакета `cucumber`) принимает AirPlay 2 через
общий аудиовыход станции. RTSP-порт — **5000**. Алиса может отвечать во время
воспроизведения.

## Возможности

Миди поддерживает голосовое управление AirPlay, приглушение музыки при
ответах Алисы, двустороннюю синхронизацию громкости и паузу/продолжение
коротким нажатием кнопки Алисы. Эти функции проверены на одной колонке.
Мультирум и длительная стабильность не проверены.

Для управления launcher должен передавать конфигурацию супервизору
через `--controls-config`. Без этого флага приёмник работает в аудиорежиме.

## Запуск и настройка

Используется пакет `airplay/airplay-luna` под управлением Luna.
[Общая установка](INSTALLATION.md).

Launcher должен передавать существующий файл настроек:

```sh
exec "$here/bin/station-airplay" --shared-audio --controls-config "$config"
```

`config` указывает на `$LUNA_PLUGIN_STATE/airplay-controls.json`.
Передача конфигурации должна быть включена в оболочку пакета.

Пример конфигурации:

```json
{
  "voice": true,
  "native_volume": true,
  "ducking": true,
  "leds": true,
  "led_level": 200,
  "native_player": true,
  "alice_button": true
}
```

Значения и зависимости полей описаны в [справочнике конфигурации](CONFIGURATION.md).

Настройка системного D-Bus и учётной записи Avahi не требуется:
приёмник запускает их в изолированном окружении. Временные файлы
хранятся в `/run/station-airplay`.

## Аудиовыход

Shairport Sync использует ALSA из прошивки (`/usr/lib/libasound.so.2`)
и общий выход `speakers`. Формат вывода — 96 кГц, S16_LE, стерео.
На проверенной прошивке штатный микшер работает на 96 кГц; ограничение
вывода 48 кГц не проходит проверку возможностей ALSA в Shairport Sync.

Звук идёт напрямую в микшер, без отдельного процесса `aplay`.
ALSA копирует PCM в `/tmp/sps.fifo` для визуализатора. Независимый читатель
постоянно освобождает FIFO и может пропускать кадры визуализации,
если отрисовка отстаёт от звука.

## Громкость и индикация

С общим контроллером ползунок отправителя и громкость станции синхронизируются
в обе стороны через Luna. Во время речи Алисы приглушается только AirPlay-поток.

Без `native_volume` громкость отправителя регулирует программное
ослабление Shairport Sync поверх уровня станции. Обратной синхронизации
в этом режиме нет.

Визуализатор Миди управляет 24 светодиодами и сегментными цифрами `1..4`. Он показывает
спектр и изменения громкости, освобождает экран и кольцо после прекращения
потока и, при включённом контроллере, во время взаимодействия с Алисой.
Часовой пояс задаётся `PLUM_TZ` или `/data/shairport/tz`; по умолчанию — `MSK-3`.

Имя приёмника — `Yandex Midi AirPlay`. Если Luna передаёт комнату, она
добавляется в скобках, например `Yandex Midi AirPlay (Кабинет)`.
После изменения комнаты нужен [перезапуск плагина](ROOMS.md).
