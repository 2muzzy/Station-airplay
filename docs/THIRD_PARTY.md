# Происхождение runtime и проверка выпуска

Пакет содержит сторонние исполняемые файлы и библиотеки. Для их обновления нужны проверенные исходники, совместимость с прошивкой и лицензионные материалы; успешная Go-сборка этого не проверяет.

Исходные Avahi 0.7 и часть ARMhf-библиотек пришли из прежнего пакета Plum. Полная воспроизводимость этих компонентов остаётся ограничением исходной поставки. Shairport Sync и NQPTP обновлены в существующих путях; отдельный receiver используется для AArch64-аудио-ABI.

Shairport Sync использует GPL-3.0; Avahi — LGPL-2.1/GPL-2.0 в зависимости от компонента. У NQPTP и остальных библиотек свои условия, сохранённые в соответствующих материалах.

До публичного бинарного выпуска проверьте соответствие каждого распространяемого файла исходникам, атрибуции, патчам и инструкциям сборки. Предоставьте соответствующие исходники и материалы для перелинковки там, где это требуется. Наличие исходных архивов в Git само по себе не доказывает полноту всех материалов выпуска.

Приватные библиотеки прошивки служат входами связывания и загружаются с устройства при выполнении; не включайте их в распространяемый runtime. Новые бинарники и sysroot требуют отдельной проверки перед коммитом.
